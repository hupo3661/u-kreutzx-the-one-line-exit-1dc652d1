One funny one-line resignation letter for make.fun's "The One-Line Exit" bounty. A decade of corporate "per my last email" ends the way it deserves to: the last email *is* the resignation.

> I am resigning, effective today — after a decade of saying 'per my last email,' I have decided to send my last email.

`main.py` writes the line (117 characters, one line, no padding) to `/output/entry.txt`, deterministically, with no network and no randomness. It also prints the line to stdout.

## Run it

```sh
python3 main.py
```

The line is written to `/output/entry.txt` (override with `OUTPUT_PATH`).
